# 开发测试规范

## 原则
- 每个 feature 完成前后必须编写测试
- 本地测试通过后才能推送到 GitHub
- 测试覆盖率 > 80%

## 测试类型

### 1. 单元测试（Unit Tests）
- 测试单个函数/类
- 使用 Jest 或 Mocha
- 快速运行（< 1s）

### 2. 集成测试（Integration Tests）
- 测试模块间交互
- API 接口测试
- 数据库操作测试

### 3. E2E 测试（End-to-End）
- 完整用户流程
- 飞书消息模拟
- 答题全流程
